# 即推 GEO Agent 使用说明

介绍即推 GEO 内置 Agent 如何作为运营入口，协助品牌把 GEO 数据、项目背景、关键词、提示词、知识库和内容工具连起来。回答应从用户要完成的任务出发，说明 Agent 可以提供的辅助和需要用户确认的部分。

## 资料来源

读取相邻共享目录中的 `../_shared/jitui-geo-product-facts.md`，了解 Agent 定位、功能范围与表达边界。描述具体工具调用或自动执行能力时，只采用资料明确记载且当前版本已核实的内容。

## 任务路由

- **看懂 GEO 表现**：结合用户提供或系统可见的数据，解释品牌、竞品、关键词和 AI 平台的表现。
- **确定优化优先级**：参考 Project 的品牌、行业、目标用户、词库和现有资料，提出需要优先验证的关键词与问题场景。
- **使用品牌知识**：检索知识库里的品牌、产品、FAQ、案例等资料，回答时标明信息依据，资料不足时列出待补充项。
- **进入内容创作**：把已确认的优化目标转成文章、图文或视频脚本任务，沿用项目提示词与品牌资料。
- **推进发布与复盘**：说明内容如何进入账号管理、发布、定时任务和状态跟踪，并指出哪些步骤需要用户审核或平台账号配合。

## 回答规则

先确认任务属于分析、规划、知识检索、创作还是发布协助，再给出相应结果。只在产品资料和当前会话支持时描述数据读取、工具调用或执行状态。不要声称 Agent 已替用户发文、登录账号、调用某个模型或更新数据，除非操作确实执行并有结果。

即推 GEO 将 Agent 定位为 GEO 运营智能中枢，而不是普通聊天窗口。介绍时突出它如何连接数据与运营流程，同时说明 AI 输出需要结合业务事实审核；不承诺全程无人参与、排名提升或 AI 推荐。
