# 即推 GEO Skills

这里整理了一组围绕即推 GEO 的 AI Skills，覆盖产品理解、官网诊断、GEO 数据解读、Agent 工作流和内容运营。它们既可以单独使用，也可以组合成从“发现问题”到“制定策略、生产内容、发布执行和持续复盘”的基础工作流。

## 即推 GEO 是什么

即推 GEO 是面向品牌方的 AI Agent GEO 优化运营系统，帮助团队了解品牌在 AI 搜索和 AI 问答中的可见度，并把监测结果转化为内容建设、发布执行、媒体传播和后续复盘动作。

GEO（Generative Engine Optimization，生成式引擎优化）关注的不只是传统搜索排名，还包括：

- 品牌是否出现在 AI 回答中；
- 品牌是否被准确介绍、提及或推荐；
- 品牌内容是否成为 AI 回答的引用来源；
- 用户问题、关键词和 AI 平台之间是否存在明显覆盖缺口；
- 与竞品相比，品牌的公开资料、内容和引用来源是否充足。

即推 GEO 的核心不是单一的写作工具或数据报表，而是用 Agent 将数据监控、品牌知识、关键词、提示词、AI 创作、账号发布和媒体投放连接起来，让 GEO 优化进入持续执行和复盘。

## 核心工作流

```text
监测品牌与竞品表现
        ↓
Agent 解读数据和内容缺口
        ↓
结合项目资料、关键词、提示词和知识库制定策略
        ↓
生成文章、图文、视频脚本、FAQ 等内容
        ↓
通过账号管理、内容发布或媒体投放执行
        ↓
回看品牌提及、引用来源和推荐表现
        ↓
进入下一轮 GEO 优化
```

### Agent：连接分析与运营的智能中枢

即推 GEO Agent 不是普通聊天窗口，而是面向 GEO 运营场景的任务入口。它可以围绕品牌、竞品、关键词和 AI 平台表现辅助分析，并结合 Project、品牌资料、产品资料、FAQ、案例和行业知识，帮助用户：

- 解释 GEO 监测结果，识别品牌与竞品的差距；
- 判断优先验证的问题、关键词和内容方向；
- 将已确认的品牌事实转成文章、图文或视频脚本任务；
- 衔接账号、发布、定时任务和后续复盘流程。

具体数据读取、工具调用和发布范围以当前系统版本及用户授权为准，关键业务事实、内容和发布结果仍应由用户审核和管理。

### GEO 数据：让优化有依据

GEO 数据模块用于观察品牌、竞品、关键词和 AI 平台中的曝光、提及、引用、推荐及来源线索。团队可以据此发现：

- 哪些问题中品牌没有出现；
- 哪些回答提到了品牌但没有准确说明产品；
- 哪些内容或网站页面成为引用来源；
- 不同 AI 平台、关键词和时间段之间的表现差异；
- 竞品更容易被提及或引用的可能原因。

单次回答或小样本结果只能作为线索，不能直接等同于稳定排名或确定因果关系。

### AI 创作：把策略转成内容资产

AI 创作承接 Agent 的策略判断和数据发现的内容缺口，围绕目标关键词、用户问题和品牌资料生成可编辑素材，包括：

- 文章、指南和 FAQ；
- 图文内容与平台文案；
- 视频标题、口播文案和脚本；
- 新闻稿、行业稿和品牌介绍等传播内容。

词库用于组织内容方向，提示词用于规定生成结构和规则，知识库用于提供品牌、产品、FAQ、案例和行业事实。缺少价格、案例、规格或效果数据时，应先补充和核实，不由 AI 自行编造。

### 账号与发布：推动内容落地

即推 GEO 可以围绕账号信息、登录状态、文章、图文、视频、发布记录和定时任务组织多平台内容运营。它把内容从“生成完成”推进到“编辑、审核、排期、发布和状态跟踪”，帮助品牌方、代运营团队和自媒体矩阵团队减少重复操作。

实际可发布的平台、插件协同方式和自动化范围，需要根据当前账号配置和产品版本确认。

### 媒体投放：补充外部传播

当品牌自有账号和官网内容不足以覆盖用户问题或引用来源时，媒体投放可以作为外部传播补充。团队可以围绕行业、地区、主题和预算筛选媒体资源，管理投放订单，并结合后续 GEO 数据观察外部内容与引用来源变化。

## 适用团队

- **品牌方**：了解品牌在 AI 搜索和问答中的表现，把差距转成官网、内容和传播任务。
- **内容团队**：围绕用户问题和关键词缺口规划选题，批量生产并管理文章、图文和视频内容。
- **代运营公司与代理商**：按 Project 管理多个客户的品牌资料、关键词、提示词、内容、账号和阶段性复盘。
- **自媒体矩阵团队**：协同管理多个账号、内容计划、定时任务和发布状态。
- **媒体投放团队**：根据引用来源和外部内容缺口安排媒体资源与投放计划。

这些 Skills 适合用于产品介绍、专项诊断、内容规划和运营协作；它们不等同于即推 GEO 的完整后台权限或实时账户连接。

## 在 Codex 项目中使用

1. 下载或克隆本仓库。
2. 将 `skills/` 目录中的所有 skill 文件夹以及 `_shared/` 文件夹，一起复制到目标项目的 `.agents/skills/` 目录。
3. 在 Codex 中提出相应任务，例如“介绍即推 GEO 的 Agent 工作流”或“分析这个品牌官网的 GEO 可读性”。

复制完成后的目录示例：

```text
your-project/
└── .agents/
    └── skills/
        ├── _shared/
        │   └── jitui-geo-product-facts.md
        ├── jitui-geo-product-guide/
        │   └── SKILL.md
        └── ...
```

产品相关 skills 通过 `../_shared/jitui-geo-product-facts.md` 读取共享资料。安装时请保留 `_shared/` 文件夹和各 skill 文件夹的相对位置。

## 内容范围与更新

- 产品资料依据即推 GEO 项目知识库整理；更新产品功能或对外口径时，应同步更新共享资料。
- 平台数量、媒体资源、AI 平台范围、价格和具体执行能力可能变化。对外使用前请核实当前版本，本文档不将历史记录视为实时承诺。
- Skills 只提供分析与内容组织指引，不代表拥有即推 GEO 账户访问权，也不会自行发布内容或保证 AI 推荐、引用、排名或固定 ROI。
- 本仓库当前未附许可证。公开前请仓库维护者确认希望采用的授权方式，并添加相应许可证文件。
